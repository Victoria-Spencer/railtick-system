# 🗄️ 缓存元数据治理中台说明
为解决分布式微服务架构下缓存失效粒度粗、一致性保障难、业务接入成本高、运维管控缺失的痛点，本项目规划接入自研缓存元数据治理中台，实现缓存全生命周期自动化治理，为高并发购票场景提供更稳定的缓存层支撑。

## 核心能力
- **零侵入接入**：自研Spring Boot Starter SDK，通过AOP切面自动拦截SQL执行与事务提交，自动触发对应缓存失效，业务方无需修改核心业务代码即可完成接入
- **多模式失效保障**：支持强一致/异步双失效策略，SQL同步失效 + Canal Binlog监听兜底双链路，保障缓存与数据库数据最终一致性
- **灵活规则配置**：支持TTL随机偏移、热点Key互斥锁、二级缓存开关、降级熔断等10余项策略配置，适配不同业务可靠性要求
- **自愈调度体系**：失效失败自动重试、连接故障自愈、缓存不一致自动巡检修复与死信兜底
- **全链路可观测**：覆盖Redis实例监控、字段级缓存命中率统计、一致性状态监控，实现缓存全生命周期可管可控
